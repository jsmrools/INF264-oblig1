This project is part of the INF264 course and focuses on implementing and evaluating decision trees and random forests. Our implementation is compared against scikit-learn’s corresponding models

- To reproduce the results presented in the report, open and run the notebook:

run_experiments.ipynb (run all cells sequentially).

****Project Structure:

- decision_tree.py – custom implementation of a Decision Tree.

- random_forest.py – custom implementation of a Random Forest.

- run_experiments.ipynb – notebook for running experiments and generating results.

- report.tex / report.pdf – written report for the assignment.

****The code has been tested with Python 3.10+.

****Required Python libraries:

NumPy

scikit-learn

Random seeds are fixed for reproducibility.

****Training and evaluation may take a few minutes depending on hardware.
- Random Forest implementation in the jupiternotebook takes roughly 10 minutes to run and is essential for the code following
